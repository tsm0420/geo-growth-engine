# Roadmap

Current main covers project-scoped skills, static export audits, store-text limits, fact-linked content opportunities, visibility imports, report/input protection, installation preflight, retained-report comparison and CI/report workflows. The published alpha 1 tag preserves its original scope; the [later integration](integration-outcome-2026-10-18.md) is unreleased. Technical readiness is not a growth forecast.

| Capability | Status and prerequisite |
| --- | --- |
| Live HTTP audit | Deferred; bounded fetching, redirects, header evidence, and explicit network scope. |
| Rendering/framework adapters | Deferred; choose framework and test actual generated output. |
| Schema.org semantic validation | Deferred; separate vocabulary checks from platform eligibility. |
| AI provider sampling | Deferred; supported APIs, credentials, budget, retries, raw answers and citations. |
| Consumer-interface measurements | Deferred; supported access and interface-specific conditions. |
| Content generation and fix PRs | Deferred; product evidence, actual build tests, and human publication review. |
| App Store/Google Play integration | Deferred; account/API access and listing/experiment contracts. |
| Referral/conversion attribution | Deferred; actual analytics and install events. |
| Dashboard and multi-product hosting | Deferred; the selected first release is a toolkit. |
| Other agent discovery directories | Deferred; `.agents/skills` is the implemented target. |

The original 30-day schedule is an ordering proposal, not a deadline or ranking promise. Improve this system using observed failures and measured outcomes.
