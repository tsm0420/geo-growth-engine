Run GEO Growth Engine's `geo plan --config <config> --output <directory>`. Queries link to explicit product-fact IDs; unsupported queries become research gaps. If the CLI is unavailable, identify the prerequisite.

Read sources before drafting. A supplied source URL is a traceability pointer until inspected. Give each page distinct value and preserve supporting fact IDs. Comparisons need current evidence for both products. Request missing evidence instead of inventing capabilities, prices, testimonials, or demand.

The CLI produces opportunities, not publishable pages or traffic estimates. Explain which supplied query each opportunity serves. Keep later edits and PRs within the user's authorized scope. Avoid keyword-only page variants.
